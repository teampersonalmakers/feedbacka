## 2단계. 승인 작업 화면 정비 — 오늘

내가 승인을 빨리 하려면 화면이 이래야 해.

### 2-1. 플레이북 (playbook.html)
- `답변작성` 상태 50건을 한 화면에서 순서대로 넘기며 승인/수정/보류할 수 있게. 한 건씩 페이지 이동하지 않게.
- 각 건에 질문 / 디렉터 답변 / 수강생 / 카테고리 / 작성일 표시. 답변 인라인 수정 후 승인.
- 승인 즉시 벡터 upsert (이미 구현돼 있으면 확인만).
- 중복 4건(25자짜리 "캡컷 추천", "제이콥님 방향성", "트랜드 소재", "조회수 안 나와요")은 id 보여주고 내 확인 후 삭제.

### 2-2. 디렉팅 사례 (settings.html › 디렉팅 사례 › 초안 탭)
- 초안 742장을 사전 검수 점수 내림차순으로. 점수 없는 카드는 맨 뒤.
- **5점 탭: 10% 샘플 확인 후 일괄 승인.** 5점 카드 목록에서 무작위 10%를 상단에 "샘플" 표시로 뽑아주고, 그것만 열어보고 "5점 전체 승인" 버튼 한 번. 샘플 중 틀린 게 있으면 그 카드만 보류하고 나머지 승인.
- **3~4점 탭: 내가 한 장씩.** 카드마다 승인 / 보류 버튼, 키보드 단축키(→ 승인, ↓ 보류)로 넘기게. 검수 AI의 issue(문제 한 줄)와 evidence(녹취 발췌)를 카드 상단에 먼저 보여줘. 그것만 보고 판단할 거야.
- **1~2점: "전체 보류" 버튼 한 번.** 삭제는 안 함, AI 참고 대상에서만 빠지면 됨.
- 점수 없는 카드(742 중 439장)는 별도 탭. vercel.json에 cron 추가해서 매일 한국시간 새벽 3시에 `/api/distill?prereview=1`을 돌려 점수 없는 카드를 전부 검수. 로그인 트리거는 유지. "지금 전체 검수" 버튼도 소유자 전용으로 하나(API 비용 안내 포함).
- 승인 화면 옆에 `제2의커밍쏜_기준서.md` 2-1 표(승인 조건 5개)를 고정 패널로 띄워줘.
- 카드 하나 열면 summary / situation / diagnosis / prescription / quote / evidence(검수 AI가 뽑은 녹취 발췌) 한 화면에.

### 2-3. 승인 후 벡터 반영
- 백필이 10분 스로틀이라 일괄 승인 직후엔 안 올라갈 수 있어. 승인 화면에 "지금 벡터 반영" 버튼 하나. 소유자 전용.

## 3단계. 디렉터 화면 — 이번 주

### 3-1. 👍👎 강제
- 답변 받은 뒤 👍👎 안 누르면 다음 질문 입력창 비활성. 👎는 한 줄 코멘트 필수.
- 👎 → 플레이북 '대기' 자동 등록은 이미 있음. 등록 시 디렉터 이름·수강생·원본 질문·AI 답변 전문이 들어가는지 확인.

### 3-2. "커밍쏜 확인 필요" 표시
- 답변 마지막 줄이 "커밍쏜 확인 필요"로 끝나면 답변 카드 상단에 배지 + "커밍쏜에게 보내기" 버튼.
- 버튼 누르면 플레이북 '대기'에 유형=확인요청으로 등록. 👎와 구분.
- "디렉터 선에서 마무리"로 끝나면 배지 없음.

### 3-3. 대기 큐 알림
- 플레이북 '대기'(👎 + 확인요청)에 새 항목 생기면 나한테 알림. 슬랙 웹훅이 있으면 슬랙, 없으면 설정 화면 상단 카운트 배지라도.
